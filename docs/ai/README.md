# Hub de Contexto de IA

Este diretório centraliza o contexto que normalmente teria de ser explicado de novo para cada agente.

A documentação pública está em [../README.md](../README.md). Este contexto complementa os guias do aplicativo e não é requisito para usar o SyncSphere.

## Uso Rápido

- Para entender o projeto: leia [project-context.md](project-context.md) e [a arquitetura pública](../architecture.md).
- Para configurar comportamento de agentes: leia [agent-tooling.md](agent-tooling.md) e [skill-policy.md](skill-policy.md).
- Para escolher MCPs: leia [mcp-catalog.md](mcp-catalog.md).
- Para pedir tarefas recorrentes com menos atrito: use [prompt-recipes.md](prompt-recipes.md).
- Para preparar e publicar versões: siga [release-process.md](release-process.md).
- Para a entrada de uma sessão: comece por [AGENTS.md](../../AGENTS.md) e [agent-onboarding.md](agent-onboarding.md).

## Manutenção

Atualize estes documentos sempre que mudar:

- portas, scripts ou variáveis de ambiente;
- arquitetura de auth, filas, sockets ou integrações externas;
- padrões de UI e sistema de design;
- MCPs usados no dia a dia;
- ferramentas de agentes, hooks e política de skills;
- prompts que se repetem em tarefas frequentes.

Regra prática: se você teve que explicar algo duas vezes para uma IA, isso pertence aqui.
