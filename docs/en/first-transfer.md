# Your first transfer

[Documentation](README.md) · [Português (Brasil)](../primeira-migracao.md)

1. Open SyncSphere and select **English** in the header if needed.
2. Choose **Try without accounts**. It imports **My first playlist** and selects File as source and destination.
3. Use **View tracks** to inspect the three fictional occurrences. One track repeats intentionally.
4. Choose **Review and transfer**. Read the summary, then confirm **Transfer 1 playlist**.
5. Follow the outcome. The expected result is three tracks added, preserving the repeat.
6. Open **History > View details** to download the playlist or a CSV/JSON report.

This demonstration uses local File providers, without accessing music accounts. It transfers metadata, not audio files. If you import your own file, playlist names, track names, artists and descriptions stay in their original language when you switch the interface.

For a service transfer, follow **Source > Destination > Connections > Playlists > Outcome**. Configure only the selected providers. Check the destination and selected playlists before confirming: a real service transfer can create playlists in your connected account.

**Help and security** includes a demonstration video recorded with the Portuguese interface, with Portuguese and English captions and a text description. It also provides symptom-based help, protected backups and a diagnostic preview.
