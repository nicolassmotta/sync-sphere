# SyncSphere 1.1.0

Estado: versão preparada para validação e publicação posterior. A data e o commit de publicação serão definidos ao criar a release.

## O que muda

- Sete provedores: Spotify, YouTube Music, Deezer, TIDAL, Apple Music, SoundCloud e Arquivo.
- Importação e exportação em CSV, JSON, M3U/M3U8 e TXT. Arquivo -> Arquivo permite converter formatos.
- Fila local persistida com raias por destino, ETA, pausas automáticas, reconexão e retry de pendências.
- Cache cifrado de correspondências confiáveis com validade de sete dias.
- Revisão manual no Histórico: ajuste a busca, confira a alternativa e confirme sua inserção.
- Reconciliação por quantidade para preservar repetições intencionais e evitar reenviar ocorrências após escrita parcial.
- Escrita local atômica dos arquivos cifrados.
- Endpoints atuais do Spotify para criação e manipulação de playlists.
- Dependências corrigidas e Vite 6.4.3 no desenvolvimento do frontend.

## Atualizar uma instalação

1. Faça backup de `backend/data/`, incluindo `encryption.key` quando ela for gerada localmente, e preserve a configuração do `.env`.
2. Atualize o código para o commit ou tag desta versão quando publicada.
3. Rode `npm ci --prefix backend` e `npm ci --prefix frontend`.
4. Gere o frontend com `npm run build` e reinicie com `npm start`.
5. Confira `/api/ready`, as integrações e o histórico antes de iniciar uma nova transferência.

A chave usada para cifrar dados antigos deve ser mantida. Os registros antigos de transferências continuam reconhecidos; a revisão manual requer registros com estado por faixa.

## Limites de validação

Escritas em Deezer, TIDAL, Apple Music e SoundCloud têm testes automatizados com respostas simuladas. A confirmação com contas reais depende de credenciais e continua pendente.

Algumas integrações usam APIs não oficiais e podem mudar sem aviso. Consulte o README para autenticação, privacidade e limites por plataforma. Faixas recuperadas posteriormente entram no fim das playlists remotas; exportações em Arquivo seguem a ordem da origem.
